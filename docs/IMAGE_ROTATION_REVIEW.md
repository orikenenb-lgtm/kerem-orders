# דוח ביקורת סיבובי תמונות — לאישור הבעלים בלבד

**כלל הענף:** אף `rotation_override` לא נשמר ולא יישמר מתוך הענף הזה.
הדוח הזה הוא רשימת עבודה לאישור — היישום ייעשה רק אחרי אישור מפורש,
דרך מסך `admin/images-review` (שכעת שומר רק בלחיצת "שמירה" מפורשת).

הסיבובים הקיימים הוחלו בסבבים קודמים (לפני כללי-ההקפאה של ענף זה) דרך
כלי האדמין וסריקות מאושרות. צנרת `rivhit-img` מיישרת אוטומטית תמונות עם
EXIF; ‏`rotation_override` נועד לתמונות שצולמו עקום בלי EXIF.

## איך מאשרים ומיישמים (אחרי החלטת בעלים)

1. פותחים את `ניהול → יישור תמונות` (admin/images-review).
2. מאתרים כל מוצר מהטבלה (חיפוש לפי שם/SKU).
3. בוחרים את הסיבוב המוצע — המסך מציג **תצוגה מקדימה בלבד**.
4. לוחצים "שמירה" רק אם התצוגה נכונה. השינוי חי מיד (הסיבוב חלק ממפתח
   הקאש של התמונה).
