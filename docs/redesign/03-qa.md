# Premium redesign — QA, performance and review

All checks below ran on this machine against **production static builds**
(`npm run build`, served locally under `/kerem-orders`) of the baseline
`e4227d3` and of the redesign branch. Supabase, Auth and the image proxy were
**mocked with synthetic data** (fake products, fake photos, a fake test
customer); every non-GET request to the database or to any function was
refused and recorded — **0 write attempts** in every run. No real customer,
order, quote, WhatsApp message or Rivhit call was involved.

Reading the table:
* `/collection` on the phone: the LCP *element* changed, not the speed. On the
  baseline the largest element was a small text paragraph (painted at ~100 ms);
  with the bigger photo frames the largest element is now the first product
  photo, which paints at ~280 ms — the same moment as before (the same photo on
  `/view` is 288 ms on both builds).
* CLS (layout shift) improved on every page that had it; home desktop 0.03 is
  the header settling after the sign-in check (under the 0.1 "good" line).
* The public `/view` banner is taller on desktop (guest call to action inside
  it), so products start ~160 px lower there; on the customer `/catalog` they
  start ~150 px higher than before on both widths.
* Sticky bars on `/catalog` after scrolling: 292 px of 844 on the phone
  (baseline 298), 276 px of 900 on desktop (baseline 268).

## Independent reviews

### Code review (logic safety) — findings and what was done

| # | Finding | Action |
|---|---|---|
| 1–2 | New `?cat=` link (home tiles → catalogue) could leave an empty grid for an unknown category; `/view` read the URL in initial state (hydration risk) | Fixed: applied only after the real category list loads and only for a known name; unknown → "הכל". Verified: valid → 17 products + chip pressed; unknown → all products |
| 3 | Home page is a rewrite, not a reskin (reads public categories + 8 public products, no prices; signed-in visitors get "לקטלוג") | Intended by the brief (real categories, real products). Flagged to the owner for approval |
| 4 | Product page showed new "מארז = N" / "קרטון = N" facts with a different carton rule than the catalogue | Removed — business info is out of scope |
| 5 | Flag comment claimed a full rollback | Comment corrected; rollback doc already says: flag = colours only, full rollback = `git revert` |
| 6 | Phone header hid the shipping / VAT lines | Restored (they were visible before) — the strip wraps instead |
| 7 | Phone nav moved into a "תפריט" disclosure | Kept (Escape / focus return / aria verified) |
| 8 | `/view` guest box also shown to signed-in customers | Signed-in customers now get the link to their catalogue instead |
| 9 | `/admin` shows the new header structure in the old colours | Kept, documented; admin pages themselves unchanged |
| 10 | Home sections start hidden until scrolled to (Reveal) | Only when JS runs and IntersectionObserver exists; no-JS and reduced-motion show everything |

Business logic verified unchanged by the reviewer: prices, discounts, VAT,
minimum order, totals, cart keys and shape, order submission and payloads,
Supabase price / order queries, auth and role checks, captcha, submit gating.
No Hebrew business text was removed. One `setQty` per click — no double add.

### Design / accessibility review — findings and what was done

| Area | Result |
|---|---|
| Contrast | Every solid text/background pair passes AA (ink on yellow 11.9:1, ink on pastels ≥ 13.5:1, dim on lavender 5.1:1). **Fixed:** `/catalog` hero pills were 4.1–4.4:1 → darker veil behind white text. Large hero text over the gradient ≥ 3.8:1 (passes the 3:1 large-text rule). The multicolour wordmark is a logo (exempt) |
| Reduced motion | No running animations, all reveal sections visible, hover transforms off, decorative floats stopped — pass |
| No JavaScript | Home fully visible (reveal never armed without JS) — pass. `/catalog` is a sign-in page and shows "טוען…" without JS, as before |
| Keyboard | Visible focus on all 45 stops; skip link; "תפריט" opens with Enter, Escape closes and returns focus. **Fixed:** focus could land under the sticky header on Shift+Tab — now 0/40 on home, `/view`, `/catalog` (baseline had 10–27/40) |
| Headings | Exactly one h1 on every page checked |
| Touch targets (390 px) | Primary actions ≥ 44 px. **Fixed:** catalogue steppers 40 → 44 px. Secondary controls (chips 38–40 px, small text links) ≥ 24 px minimum; dense 3–4-per-row grids keep 30 px steppers (the customer's own choice of density) |
| Motion timing | **Fixed:** hover zooms 320 → 200 ms (feedback range) |
| RTL | **Fixed:** one physical `text-align: left` → `end` |

Known and left as is (documented): `/catalog` sticky search + chips height (same
as the baseline); chips are clipped at the edge of the scrolling strip (it is a
scroller); with `?cat=` the selected chip can sit off-screen in the collapsed
strip (the banner count shows the filtered total); the mobile menu stays open
if you Tab out of it; `/view` for a signed-in visitor shifts once when the
call to action switches (desktop CLS 0.31 in that state).
