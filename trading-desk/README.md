# 🖥️ Claude × TradingView — ערכת התקנה מלאה

ערכה זו מיישמת את המדריך "The Claude × TradingView Setup" (@gobi_automates).
היא בנויה משני חצאים:

1. **הדסק המקומי (הלפטופ שלך)** — Claude Code מחובר ל-TradingView Desktop דרך MCP:
   קורא אינדיקטורים, כותב Pine Script, מריץ Strategy Tester, משחזר היסטוריה (Bar Replay).
2. **המוח בענן (Hermes)** — סוכן 24×7 שרץ על מודלים של Claude, שולח תדריכים לטלגרם
   ומריץ בדיקות תקופתיות. **אופציונלי** — ראה אזהרות בסוף.

> ⚠️ **החצי המקומי חייב לרוץ על המחשב שלך.** ה-MCP שולט באפליקציית TradingView Desktop
> עם ממשק גרפי — אי אפשר להריץ אותו משרת ענן. הקבצים כאן מוכנים להעתקה והרצה אצלך.

> 🔒 **אף שלב כאן לא דורש למסור סיסמה לאף אחד (כולל ל-Claude).**
> TradingView — משתמשים באפליקציה שכבר מחוברת. ברוקר — מתחברים דרך מסך ההתחברות
> הרשמי שלהם (2FA). אם משהו מבקש ממך סיסמה — עצור.

## חלק 1 — חיבור Claude ⇄ TradingView (~15 דקות, על הלפטופ)

### דרישות מקדימות
- **TradingView Desktop** (האפליקציה, לא הדפדפן) — מחובר לחשבון שלך. כל תוכנית עובדת; בתשלום = דאטה בזמן אמת.
- **Claude Code** — התקנה מ-[claude.com/claude-code](https://claude.com/claude-code) (דורש Node 18+).
- **שרת ה-MCP** — [github.com/tradesdontlie/tradingview-mcp](https://github.com/tradesdontlie/tradingview-mcp)
  (78 כלים; עובד דרך Chrome DevTools Protocol — הכל מקומי, שום דבר לא עוזב את המחשב).

### חמשת הצעדים

**1. שכפל והתקן את השרת:**

```bash
git clone https://github.com/tradesdontlie/tradingview-mcp.git ~/tradingview-mcp
cd ~/tradingview-mcp
npm install
```

**2. רשום אותו ב-Claude Code** — העתק את `mcp.json.example` שבתיקייה הזו אל
`~/.claude/.mcp.json` (או מזג לתוך קובץ קיים), והחלף את `<INSTALL_PATH>` בנתיב האמיתי
(למשל `/Users/you/tradingview-mcp`).

**3. הפעל את TradingView Desktop עם פורט דיבאג פתוח:**

- **Mac:** הרץ את `scripts/launch_tv_debug_mac.sh` שבתיקייה הזו.
- **Windows:** הרץ את `scripts/launch_tv_debug_windows.bat`
  (או את `scripts\launch_tv_debug.bat` שמגיע עם הריפו של ה-MCP).

**4. הפעל מחדש את Claude Code** כדי שיקלוט את שרת ה-MCP החדש.

**5. אמת את החיבור** — בקש מ-Claude להריץ `tv_health_check`. אתה רוצה לראות:

```json
"success": true, "cdp_connected": true, "api_available": true
```

### חלופה בלי התקנה
אין אפליקציית Desktop? צלם מסך של גרף, הדבק ל-Claude ובקש את אותו ניתוח.
מאבדים את החיבור החי (אין קומפילציית Pine ואין Strategy Tester), אבל ההיגיון זהה.

## חלק 2 — שיחות ראשונות עם הגרף

ברגע שהחיבור חי, Claude רואה את מצב הגרף ישירות. פרומפטים מוכנים ב-[`PROMPTS.md`](PROMPTS.md).

כלים שימושיים מאחורי הקלעים: `chart_get_state` (מה על המסך), `data_get_study_values`
(ערכי אינדיקטורים חיים), `data_get_ohlcv` עם `summary=true` (היסטוריית מחיר),
`capture_screenshot` (קריאה ויזואלית).

## חלק 3 — כתיבת Pine Script עם Claude

לולאת פיתוח מלאה על הגרף:
1. מתארים את האסטרטגיה באנגלית פשוטה (או נותנים ל-Claude קוד Python קיים).
2. Claude כותב Pine v6 ומזריק לעורך (`pine_set_source`).
3. מקמפל (`pine_smart_compile`), קורא שגיאות (`pine_get_errors`) ומתקן.
4. שומרים — והאסטרטגיה על הגרף: סיגנלים, גרפים, התראות.

---

## חלק 4 — בדיקת אסטרטגיות וביקורת עצמית

עם `strategy()` על הגרף, ה-Strategy Tester הופך למעבדה: Claude קורא רווח נקי, אחוז
הצלחה, Profit Factor, Drawdown וכל טרייד (`data_get_strategy_results`, `data_get_trades`).

**תהליך הביקורת (Audit):** מריצים את אותה אסטרטגיה בשני מנועים בלתי-תלויים
(Python שלך מול TradingView) ומיישבים כל מספר. פער = באג אמיתי אצל אחד מהם.
זה הדבר הכי שווה בכל ההתקנה.

**איך נראים מספרים כנים** (מהמדריך המקורי):
- 0 מתוך 40 ריצות אסטרטגיה×מכשיר ניצחו Buy & Hold על CAGR גולמי (2012–2026).
- corr(win rate, CAGR) = ‎+0.20 — אחוז הצלחה כמעט לא מסביר כמה מרוויחים בפועל.
- היתרון מופיע ליחידת סיכון (Sharpe), לא כסיפור התעשרות.
- חובה: לתמחר עמלות בשני הצדדים, להגדיר סטופים, להתעלם מתאים עם פחות מ-30 טריידים,
  ולבדוק דרך 2008 ו-2020 — לא רק שנות שור.

## חלק 5 — מצב נייר (Paper) לפני שזז שקל

- **Bar Replay מובנה:** Claude מחזיר את הגרף לכל תאריך וסוחר קדימה נר-אחר-נר
  (`replay_start` → `replay_step` → `replay_trade`). הוא לא רואה את העתיד — וכך גם האסטרטגיה.
- **כלל ברזל:** מינימום 30 טריידים בנייר או 4 שבועות מלאים (הארוך מביניהם), עם תוצאות
  בטווח 20% מהבקטסט — לפני שמשהו הופך אמיתי. וגם אז — **בן־אדם לוחץ על הכפתור.**

## חלק 6 — חיבור ברוקר (קריאה בלבד קודם!)

הוסף לאותו `~/.claude/.mcp.json` (דוגמאות מלאות ב-`mcp.json.example`):

| ברוקר | כתובת | הערות |
|---|---|---|
| **Kite (Zerodha)** — רשמי, מתארח | `https://mcp.kite.trade/mcp` | בלי מפתחות API; התחברות דרך 2FA של Kite. פקודות מסוכנות חסומות בצד השרת — מעולה ללמידה. |
| **Groww** — רשמי, מתארח | `https://mcp.groww.in/mcp` | מניות + F&O. מכירה דורשת הרשאת DDPI על הדמט. |
| **Hyperliquid** — קהילתי, קריפטו | github.com/0xikalgo/hyperliquid-mcp | לא-משמורתי — מפתח ה-API חותם. להתחיל ב-testnet, תת-חשבון קטן, מגבלות גודל בקונפיג. |

**קו הבטיחות:**
1. קריאה בלבד קודם — שבועות של MCP אנליטי לפני שקיים בכלל נתיב פקודות.
2. AI על הניתוח, אדם על ההדק — Claude מנסח טיקטים; אתה שולח.
3. מגבלות קשיחות בקוד: גודל פוזיציה מקסימלי, הפסד יומי מקסימלי, kill-switch.

## חלק 7 — Hermes בענן (אופציונלי — קרא את האזהרה)

המדריך ממליץ על סוכן Hermes מנוהל ב-myhermes.cloud (BYOK — מפתח Anthropic שלך),
מחובר לטלגרם, עם שני crons: תדריך בוקר יומי ובדיקת בריאות אסטרטגיה שבועית.
נוסחי ה-crons המלאים ב-[`PROMPTS.md`](PROMPTS.md).

> ⚠️ **לפני שמדביקים מפתח API בשירות צד-שלישי:** צור מפתח **ייעודי** ב-console.anthropic.com,
> הגדר עליו **מגבלת הוצאה חודשית**, ותהיה מוכן לבטל אותו בלחיצה. מפתח API = כסף.
> myhermes.cloud אינו שירות של Anthropic — שקול היטב אם אתה סומך עליו, או הרץ את
> Hermes (קוד פתוח של Nous Research) על VPS משלך.

## לפני שעוברים ל-Live — הכללים

- **חינוכי בלבד** — שום דבר כאן אינו ייעוץ השקעות.
- נייר קודם, תמיד: 30 טריידים / 4 שבועות מינימום, ואז קטן.
- לצפות למבקר, לא לכספומט — הטרייד הכי טוב של ההתקנה הוא לתפוס את הבאגים של עצמך.
- מגבלות סיכון קשיחות, תקרות פוזיציה, kill-switch, ואדם על כל הדק.
- מפתחות API הם כסף: מגבלות הוצאה, הרשאות קריאה-בלבד לברוקר עד שמוכח, testnet לקריפטו.
